# Hooki w Claude Code: ćwiczenia krok po kroku

Strona: https://bartekszyma.github.io/hooki-instrukcja/

Ćwiczenia K1-K11: hook na starcie i na zakończeniu, Notatnik z datą i godziną, hook globalny, blokada zapisu do folderu, kontrola plików JSON, data w prompcie, aktualizacja skilla z GitHub i hook sprzątający. Dalszy ciąg [instrukcji „Pakiet analityczny spółki”](https://bartekszyma.github.io/skill-docx-pptx-xlsx/cwiczenia-pakiet-analityczny.html).

Cała instrukcja to jeden plik `index.html` (zrzuty są osadzone w nim jako data URI).

- testy: `npm test`
- osadzenie zrzutów z folderu `zrzuty/`: `node tools/osadz-zrzuty.mjs index.html`
